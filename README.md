# ProjectBday
A personal Roblox project with many modular system that are easy to tweak such as, dialogue system, dungeon gen, loot gen, enemy AI, etc.
The scope of the game was a bit too large for me to finish within a time frame so I stopped the project. 

## Tech stack
- LUA
- Rojo (Package)
- Wally (Package)

## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "ProjectBday.rbxlx"
```

Next, open `ProjectBday.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
